# OfferGoose knowledge sync

This folder is written by **OfferGoose** (Android app + Chrome extension) and read back automatically on every Scan & Ready, so the phone, the extension and GitHub share one learning database.

- `answers.json` / `answers.md` — learned questions & answers (interview-ready)
- `documents.md` — indexed documents (CV, blueprints, notes) as readable text

Fetching works without setup because this repository is public. Publishing asks once for a GitHub token with **Contents: write** on this repository; the token never leaves your device except to api.github.com.
